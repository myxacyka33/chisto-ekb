# 🧹 Чисто Екб — Сайт клининговой компании с Telegram-CRM, системой сертификатов и умным сбором отзывов

Веб-приложение и внутренняя микро-CRM для клинингового сервиса **«Чисто Екб»** (г. Екатеринбург). Проект объединяет высококонверсионный SEO-оптимизированный фронтенд с интерактивными слайдерами «До / После», полноценную обработку медиа-заявок, генератор защищённых подарочных сертификатов и систему фильтрации клиентских отзывов через Telegram-бота.

---

## ✨ Основные возможности

### 1. Веб-сайт и SEO-ядро
* **Модульная архитектура шаблонов (Jinja2):** полное разделение контента (`app/data.py`), макросов (`ui.html`) и секций лендинга.
* **Отдельные посадочные страницы под каждую услугу (`/services/{slug}`):** динамическая генерация страниц с уникальными `title`, `meta description`, `OpenGraph` и заголовками `H1` для продвижения в поисковых системах по запросам:
  * Мытьё окон (`/services/moyka-okon`)
  * Химчистка диванов (`/services/himchistka-divanov`)
  * Уборка после ремонта (`/services/uborka-posle-remonta`)
  * Химчистка мебели (`/services/himchistka-mebeli`)
  * Чистка мебели (`/services/chistka-mebeli`)
  * Химчистка (`/services/himchistka`)
  * Уборка (`/services/uborka`)
  * Клининг (`/services/klining`)
* **Автоматическая микроразметка `Schema.org`:** JSON-LD (`LocalBusiness` и `FAQPage`) генерируется автоматически из единого словаря данных без дублирования текста.
* **Доступность (a11y) и UX:** интерактивные слайдеры сравнения «До / После» с поддержкой сенсорных экранов и клавиатуры, адаптивная вёрстка, интеграция целей Яндекс.Метрики (`lead_form`, `phone_click`, `telegram_click`).

### 2. Заявки с фото/видео и мульти-контактом
* Клиент может выбрать удобный канал связи: **Телефон, Telegram, WhatsApp, MAX, ВКонтакте или Instagram**.
* Выбор района или микрорайона Екатеринбурга из структурированного списка.
* Прикрепление до 10 фотографий или видеороликов напрямую с камеры смартфона или из галереи.

### 3. Telegram-бот (Внутренняя CRM для владельца)
* Мгновенная доставка новых заявок с медиагруппой (фото/видео альбомом).
* Прямые кликабельные номера телефонов для звонка в один тап и кнопки быстрого перехода в диалог с клиентом (Telegram / WhatsApp / VK).
* Управление жизненным циклом заказа (`🆕 Новая` $\rightarrow$ `🛠 В работе` $\rightarrow$ `✅ Выполнена` / `❌ Отменена`).
* Разделы **«📋 Новые заявки»**, **«🗂 История заявок»** и **«🎁 Сертификаты»** с быстрой подгрузкой прикреплённых медиафайлов через `tg_file_id`.

### 4. Полуавтоматические подарочные сертификаты с QR-защитой
* Оформление сертификата на сайте (номинал от $1000\text{ ₽}$, действует единовременно).
* Отображение реквизитов СБП и отправка запроса на подтверждение оплаты в Telegram-бот администратора.
* При подтверждении оплаты (`✅ Деньги пришли`) сервер с помощью `Pillow` и `qrcode` генерирует фирменный именной сертификат (`.png`) с уникальным кодом (`CHISTO-XXXX`) и зашитым крипто-токеном в QR-коде.
* Автоматическая отправка готового сертификата клиенту на Email (по протоколу SMTP) и дублирование файла в чат администратора.
* **Защита от подделки и повторного использования:** при наведении камеры смартфона мастера на QR-код открывается Telegram-бот (`/start cert_<token>`), который проверяет подлинность сертификата в БД и позволяет погасить его кнопкой `🔥 Погасить сертификат`.

### 5. «Умный» сбор отзывов (Фильтр негатива)
* Спустя 24 часа после перевода заказа в статус `🏁 Выполнено` планировщик `APScheduler` формирует персональную ссылку `/rate/{review_token}` и напоминает администратору отправить её клиенту в 1 клик.
* **Оценка 4–5 ★:** клиенту открываются кнопки для публикации отзыва на внешних площадках (**Авито, 2ГИС, Яндекс.Карты**).
* **Оценка 1–3 ★:** внешние площадки скрываются; открывается форма прямой связи с руководителем. Жалоба перехватывается и мгновенно отправляется в Telegram-бот с пометкой `🚨 ПЕРЕХВАЧЕН НЕГАТИВНЫЙ ОТЗЫВ`.

## 🛠 Технологический стек

* **Backend:** Python 3.12, FastAPI, Uvicorn
* **Шаблонизатор и Frontend:** Jinja2, Vanilla JS, CSS3 (Custom Properties / Tokens)
* **База данных:** PostgreSQL 16, SQLAlchemy 2.0 (Async), `asyncpg`
* **Telegram-бот и планировщик:** `aiogram 3.x`, `APScheduler`
* **Генерация графики и почта:** `Pillow (PIL)`, `qrcode`, `aiosmtplib`
* **Инфраструктура:** Docker, Docker Compose

## 🚀 Быстрый старт (Docker Compose)

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/chisto-ekb.git
cd chisto-ekb
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта и заполните его своими данными:

```env
DATABASE_URL=postgresql+asyncpg://postgres:postgres@db:5432/chisto_ekb
SITE_URL=https://chisto-ekb96.ru

# Настройки Telegram-бота
TG_BOT_TOKEN=123456789:AAH_ВАШ_ТОКЕН_ОТ_BOTFATHER
TG_ADMIN_ID=123456789
TG_BOT_USERNAME=имя_бота_без_собачки

# Реквизиты для приёма оплаты за сертификаты
PAYMENT_PHONE=+7 (904) 886-31-41
PAYMENT_BANK=Сбербанк / Т-Банк (СБП)
PAYMENT_RECIPIENT=Игорь М.

# Ссылки на внешние площадки для оценок 4–5 звёзд
REVIEW_AVITO_URL=https://www.avito.ru/...
REVIEW_2GIS_URL=https://2gis.ru/...
REVIEW_YANDEX_URL=https://yandex.ru/maps/...

# SMTP (Mail.ru) для автоматической отправки сертификатов на почту
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=chistoekb196@mail.ru
SMTP_PASSWORD=пароль_для_внешних_приложений_из_16_символов
```

> **Важно:** Перед отправкой первой заявки обязательно откройте созданного бота в Telegram со своего аккаунта (`TG_ADMIN_ID`) и нажмите **`/start`**, чтобы бот получил право присылать вам уведомления.

### 3. Сборка и запуск контейнеров
```bash
docker compose up -d --build
```
После запуска сайт будет доступен по адресу `http://localhost:8000`. Таблицы в базе данных PostgreSQL создаются автоматически при старте приложения.

## 🔧 Локальный запуск (без Docker)

1. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # На Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Убедитесь, что у вас запущен локальный экземпляр PostgreSQL и прописан корректный `DATABASE_URL` в `.env`.
3. Запустите сервер разработки:
   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```
