# Чисто Екб — сайт клининга в Екатеринбурге
Боевой адрес: https://chisto-ekb96.ru/

## Структура

| Файл | Что это |
| --- | --- |
| `index.html` | Весь сайт: разметка, стили (`<style>` в `<head>`) и скрипты (`<script>` внизу) в одном файле, без сборки |
| `send.php` | Приём заявок с формы: проверяет поля и отправляет письмо через `mail()` на почту из `$to` |
| `privacy.html` | Политика обработки персональных данных |
| `favicon.ico`, `favicon-120.png` | Иконка сайта |
| `images/` | Фото работ (пары «до/после») и фото мастера |

## Как запустить локально

Открыть `index.html` в браузере — всё, кроме формы, работает сразу.
Для проверки формы нужен PHP: `php -S localhost:8000` в папке проекта и открыть http://localhost:8000.
Без настроенной почты `mail()` вернёт ошибку — это ожидаемо на локальной машине.

## Что важно знать

- **Яндекс Метрика**: счётчик `113775807` подключён в `<head>`. Цели: `lead_form` (успешная отправка формы, вызывается в JS после ответа `send.php` с `ok: true`), плюс автоцели Метрики на клики по телефону и мессенджерам. Не ломайте вызов `goal('lead_form')` — на этой цели учится реклама в Яндекс Директе.
- **Реклама в Директе ведёт на якоря** `#services`, `#gallery`, `#area`, `#faq`, `#contact` и параметр `?s=...`. Не переименовывайте эти `id` без согласования.
- **Блок отзывов** (`<section id="reviews" hidden>`) готов, но скрыт до появления реальных отзывов — инструкция в комментарии над ним.
- **Разметка Schema.org** (`LocalBusiness`, `FAQPage`) лежит в `<head>`; тексты FAQ должны совпадать с видимым блоком `#faq`.
- **Хостинг** — обычный PHP-хостинг, деплой загрузкой файлов по FTP/в файловый менеджер.
